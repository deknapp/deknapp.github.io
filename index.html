xcpredict

A learned ranking model over World Cup cross-country skiing, and the database behind it.

Predicts race results from what each skier has done in races like this one — same technique, similar distance, recently — with a similarity kernel over 1,661 races and 79,725 results. Browse any of 809 athletes, see what each is actually best at, and drive the model yourself: the controls recompute every prediction in your browser.

0.826 pairwise accuracy on a season held out of training, against 0.700 for ordering by published FIS points and 0.496 for random. The kernel is what earns it — ignoring technique and distance costs 4.4 points. Fitting weights on top of it adds almost nothing.

hERG blocker prediction

A cardiotoxicity screen, and a demonstration of how much of an ML score in drug discovery is an artefact of the data split.

11,059 compounds from ChEMBL, Morgan fingerprints, scaffold-split so that chemical series are kept whole and a test compound never has a close analogue in training.

The same random forest reads 0.860 AUROC on a random split and 0.794 on a scaffold split. That 0.066 is the portion of the apparent performance that was recognising molecules it had effectively already seen — and a random split is the default in most tutorials.

chilecule

Agentic drug discovery on fully open-source tooling.

RDKit, ChEMBL, AutoDock Vina and fpocket exposed as MCP tool servers driven by Claude agents, with a strict split between a layer that computes and a layer that decides — the agent never produces a number, only calls the tool that does.

A retrospective validation harness that checks the negative set for bias before reporting any enrichment. Running the agent over real tasks found two bugs no unit test caught, including chemistry — hypobromite esters — that would otherwise have shipped.

The hosted demo is that computing layer with the agent taken off the front: profile a compound, run it past the structural alerts, and run the validation harness yourself. No key, and nothing it tells you came from a language model.

climatelens

What climate change has already done to one place on Earth.

Two thirty-year normals from ERA5 reanalysis with a bootstrapped interval on the difference, five downscaled CMIP6 models for the 2040s each differenced against its own baseline, and what El Niño winters have actually done at that point over 77 years of NOAA's index.

Has an eval harness that traces every number in the generated prose back to the computed data. It caught the model writing "at 7,000 feet" about Santa Fe — correct, and not in the payload.

Pick anywhere on Earth and it computes all of that live. The narration layer is switched off in the hosted copy, so every line on the page is the data itself.

otowi

Traffic simulation for northern New Mexico, calibrated against real count stations.

Most traffic simulations built outside transport agencies are an OpenStreetMap network plus randomly generated trips — they animate beautifully and mean nothing. Demand here comes from Census LODES commute flows and ACS departure times, and is validated against NMDOT counts on stations held out of fitting.

The model carries a fraction of measured peak traffic, and the README says so at the top with the reason. Three bugs found along the way shared a shape — a tool reporting success while silently discarding most of its input.

The map is that calibration, open to inspect: switch between what the model carries, what NMDOT actually measured, and the ratio between them — the layer where the shortfall is visible link by link rather than as one summary number.
